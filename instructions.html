⚔️ 戰略情報室 操作指南

基於 Gemini 的視覺權重競品分析與戰略報表生成器

💡 核心理念：「戰略情報室」不只比較文字內容，更透過視覺權重演算法，模擬真實使用者目光焦點，分析您與競爭對手的網頁設計重心落差。

📋 四步完成深度競品分析

1

抓取我方網頁資料 (Copy 頁面)

在瀏覽器開啟我方的產品或服務網頁，點擊彈出視窗中的 📑 抓取當前頁內容。系統會自動解析並把結構化與加權後的網頁摘要儲存起來。

2

前往競品網頁

在瀏覽器切換至競爭對手的網頁，準備分析。

3

選擇戰略分析模型

輸入 API Key 後，系統會自動向 Google 取得最新可用的 Gemini 文字模型（生圖、影片、語音、向量等模型已自動排除），Google 上架新模型或停用舊模型時清單會跟著更新，不需手動維護。
• Flash 系列：預設選擇，速度極快、價格親民且效能優異。
• Pro 系列：適合深度戰略推演，能挖掘更具洞察力的攻防策略。

4

輸入 Google Gemini API Key 並啟動分析

打開擴充功能，在密碼輸入框貼上您的 Gemini API 金鑰，輸入完後點擊 開始全頁分析 (針對競品)🚀，系統將自動開啟新分頁，產出視覺化的「雙向戰略推演與對決報告」。

🧠 核心機制與分析指標

📐 視覺權重演算法

系統根據 HTML 標籤、樣式等資料，為所有元素計算權重，篩選出並比對真正吸引使用者注意的黃金區塊。

📊 五維能力分析

報告將在以下五大核心維度，為我方與競品評分（0-100）：
1. SEO技術：Schema 結構與 Meta 設定。
2. 視覺吸睛：版面配置與重點突顯。
3. 內容深度：文字說服力與產品資訊。
4. 信任訊號：客戶見證、證書與安全保障。
5. 轉換強度：Call to Action (CTA) 的設計。

❓ 常見問題

API 金鑰安全嗎？如何更換或刪除？

所有快取資料與金鑰皆僅儲存在您本機的 Chrome 瀏覽器內。若想徹底清除，可以點選擴充功能彈出視窗下方的 🗑️ 清除所有專案快取與 Key 按鈕。

分析出現「分析失敗」怎麼辦？

請檢查您的 API Key 是否正確且有餘額，並確保當前瀏覽的網頁是一般 HTTP/HTTPS 網頁（非 Chrome 系統設定頁或本機檔案）。
